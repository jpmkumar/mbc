# Figure sources (Paper B)

Shared figure masters used by `paper/main.tex` live in [`../../../figures/`](../../../figures/).

Use this directory only for Paper-B-specific assets that should not sit in the
shared `figures/` tree (e.g. supplementary-only panels, draft composites).

Export submission copies to [`../export/`](../export/) when a fixed PNG/PDF
snapshot is needed for Word or journal upload.

Build vector figures:

```bash
./figures/build_figures.sh
```
